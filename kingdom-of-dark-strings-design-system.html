Gothic Academia Typography

Carefully selected font pairings utilizing classical serif titles and legible body fonts.

Primary Heading Font

Cinzel Serif

ABCDEFGHIJKLMNOPQRSTUVWXYZ

Inspired by classical Roman inscriptions, Cinzel conveys solemnity, elegance, and timeless neoclassical majesty.

Subtitles & Quotes Font

Cormorant Garamond

"Melancholy is the pleasure of being sad."

A traditional display serif with sharp, graceful contrast perfect for poetry, lyrics, and dark academia subheadings.

Secondary Display Font

Playfair Display

Classical Elegance & High Contrast

Ideal for editorial emphasis, article titles, and large atmospheric headers.

Clean Body Font

Montserrat Sans

Balanced sans-serif typography ensuring user interfaces, UI widgets, and dense information lists remain crisp and readable on modern screens.

:root {
  /* Kingdom of Dark Strings Aesthetic Palette */
  --color-obsidian: #0B0B0E;        /* Deep background void */
  --color-gothic-shadow: #16151A;   /* Card & panel depth */
  --color-gothic-card: #1C1A22;     /* Container background */
  --color-aged-rosewood: #332822;   /* Warm dark mahogany accent */
  --color-antique-gold: #8A724B;    /* Muted gold borders & highlights */
  --color-gold-light: #C2A662;      /* Vibrant gold text & active glow */
  --color-slate-mist: #4A5868;      /* Cold moonlight & fog tint */
  --color-pale-marble: #8E9AAF;     /* Secondary soft text */
  --color-parchment: #D9CBB0;       /* High contrast body text */

  /* Typography */
  --font-heading: 'Cinzel', serif;
  --font-subtitle: 'Cormorant Garamond', serif;
  --font-body: 'Montserrat', sans-serif;
}
